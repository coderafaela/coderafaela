## 🚀 Projetos

### 📚 [SecretChapter](https://github.com/coderafaela/SecretChapter)
Sistema em C# que organiza autores e livros, com hierarquia de classes (POO), cálculo de avaliação de cada livro e tratamento de exceções.

### 📚 [SecretChapter_API](https://github.com/coderafaela/SecretChapter)
Camada de API do SecretChapter, consumindo dados de um serviço externo (jsonbin.io), com desserialização de JSON e tratamento de wrappers aninhados.

### 🎵 [TuneRater](https://github.com/rafaela-aquevedo/tunerater)
Aplicação de terminal em C# para cadastrar e avaliar bandas e artistas solo, usando `Dictionary<string, List<double>>` para armazenar as notas. Interface com arte ASCII e menu de 9 opções.
